# Pulse media slots

No authentic Pulse app screenshots or Living Sky capture were present when this portfolio case study was prepared. Do not put recreated or illustrative interfaces in this folder as product screenshots.

When real captures are available, add optimized WebP or AVIF files here and set the corresponding URL in the root `pulse-media.js` manifest. The existing case-study layout will load the supplied media and keep its labeled placeholder when a source is unset or fails to load.

Use screenshots captured from the real app, preserve their aspect ratio, remove personal data before sharing, and write accurate alt text in `pulse-case-study.js` when adding each media source.
